# 工作区记忆

记忆默认关闭，这是 `memory` 插件自己的默认值。下次启动前打开它：

```toml
[plugins]
enable = ["memory"]
```

之后 ZettCode 保留两份持久记忆，都在项目之外：

| 范围 | 目录 | 里面是什么 |
| --- | --- | --- |
| 个人 | `~/memory/personal/` | 你本人：角色、背景、协作偏好、你给过的纠正。所有工作区共用。 |
| 项目 | `~/.zettcode/memory/<仓库>-<摘要>/` | 一个仓库：在仓库外做出的决定、代码和 git 看不出来的上下文、对这个项目的反馈。它的 worktree 共用。 |

每个目录里有一个 `MEMORY.md` 索引，以及它指向的主题文件。索引每个请求都会读；主题文件在索引说它重要时，由
agent 用自己的文件工具去读。索引一行一条指针，最多 150 个字符。索引最多加载 200 行或 25,000 字节，超过哪一条，
请求里就说明是哪一条。记忆跨会话、跨重启保留。

## 什么时候写

agent 学到一件能留下来的事时写一个主题文件：一次纠正或确认、在别处做出的决定、以后还会用到的参考。它被要求
改正或删掉被证伪的内容，合并重复，清掉过时的条目，日期写全（`2026-03-05`，不写“周四”）。长会话里过时的多半
是索引，主题文件反而少。

它也被要求不记代码、git 和 `AGENTS.md` 已经写明的东西，不记当前任务和调试过程。

## 查看和清除

有值得留下的东西之前，目录可能还不存在。随时可以看：

```bash
cat ~/memory/personal/MEMORY.md
cat ~/.zettcode/memory/*/MEMORY.md
```

删掉某个目录就是忘掉那份记忆：下一次会话从空开始，agent 重新积累。如果你让 agent 忽略记忆，它把索引当成空的。

## 隐私

记忆属于 agent，不属于你的仓库：项目里什么都不写，ZettCode 也不会提交它。两份索引每个请求都会发给你的模型
接入点，所以别把秘密放进记忆。
